# Data Structures & Algorithms

Structured Data Structures and Algorithms practice in **JavaScript**, focused on building problem-solving skills and preparing for technical interviews.

## 🎯 Purpose

This repository contains my ongoing DSA learning journey, including:

- Concept learning and notes
- Daily problem-solving practice
- Topic-wise problem solutions
- Reusable problem-solving patterns
- Mistakes, approaches, and learnings

The focus is on understanding **how to approach problems**, identify patterns, and improve problem-solving skills rather than simply collecting solutions.

## 🗂️ Repository Structure

```text
DSA/
├── daily_practice/
│   └── Current practice, experiments, mistakes, and problem-solving attempts
│
├── notes/
│   ├── concept_notes.md
│   └── patterns/
│       ├── README.md
│       └── pattern.js
│
└── problems/
    └── Topic-wise collection of understood and organized solutions
```

### `daily_practice/`

This is where I initially work on problems.

It may contain:

- Different approaches
- Experiments
- Mistakes and debugging
- Problem-solving attempts
- Temporary practice code

Once a problem and its underlying approach are understood, the solution can be organized under the relevant topic in `problems/`.

### `notes/`

Contains supporting learning notes.

- `concept_notes.md` — Notes created while learning or revising DSA concepts.
- `patterns/` — Reusable problem-solving patterns identified from problems and practice.

### `problems/`

Contains topic-wise solutions for problems that I have worked through and understood, with comments explaining the approach where useful.

## 🧠 Learning Approach

My approach is:

**Learn → Practice → Make mistakes → Understand → Identify patterns → Organize → Revise**

I use daily practice to experiment with solutions and understand where I go wrong. Problems that become clear are then organized by topic, while reusable problem-solving patterns are captured separately for future revision.
